# Tienda Informática — TP HTML + CSS

Trabajo práctico de la Cátedra de Paradigmas y Lenguajes de Programación 3 (UTN).
Sitio estático de 5 páginas servido con Apache (XAMPP) y versionado con Git.

## Estructura

```
tienda-informatica/
├── index.html            Portada
├── listado_tabla.html    Listado de productos en <table>
├── listado_box.html      Listado de productos en tarjetas (CSS Grid)
├── detalle.html          Ficha técnica de un producto
├── comprar.html          Formulario de compra
├── css/
│   └── estilos.css       Hoja de estilos única
└── img/                  Imágenes del catálogo
```

## Cómo ejecutarlo

1. Copiar esta carpeta dentro de `C:\xampp\htdocs\`.
2. Iniciar **Apache** desde el XAMPP Control Panel.
3. Abrir `http://localhost/tienda-informatica/`.

## Tecnologías

HTML5 semántico, CSS3 (Flexbox, Grid y media queries `max-width`), sin frameworks ni JavaScript.
